# ❤️ Love Polina

Небольшой сайт-подарок для Полины.

## О проекте

Этот сайт создан как личный подарок с использованием современных веб-технологий. Проект размещён на собственном VPS и доступен по HTTPS.

## Используемые технологии

- Vite
- JavaScript
- CSS3
- Caddy
- Ubuntu VPS
- Git + GitHub

## Локальный запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Деплой

```bash
deploy
```

## Сайт

https://love-polina.duckdns.org
